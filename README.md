### 🏦 Project 3 — Senior Mortgage Underwriting System

![Status](https://img.shields.io/badge/Status-Complete-brightgreen?style=flat-square)
![Type](https://img.shields.io/badge/Type-Multi_Agent_System-orange?style=flat-square)
[![LangGraph](https://img.shields.io/badge/LangGraph-00B4D8?style=flat-square)](https://langchain-ai.github.io/langgraph/)
[![ChromaDB](https://img.shields.io/badge/ChromaDB-FF6B35?style=flat-square)](https://www.trychroma.com)
[![RAG](https://img.shields.io/badge/RAG-Enabled-success?style=flat-square)](https://github.com)
[![Accuracy](https://img.shields.io/badge/Test_Accuracy-100%25-brightgreen?style=flat-square)](https://github.com)

A multi-agent AI underwriting system that automates residential mortgage loan analysis using six specialized agents coordinated through a LangGraph supervisor workflow. Agents analyze credit, income, assets, and collateral against RAG-retrieved lending policies before generating an audit-ready credit memo and final decision. Tested across three real-world applicant scenarios with 100% accuracy against expected outcomes.

| Agent | Role |
|-------|------|
| 💳 Credit Analyst | Evaluates credit score and payment history |
| 💵 Income Analyst | Verifies employment and calculates DTI |
| 💰 Asset Analyst | Confirms down payment and flags deposits |
| 🏠 Collateral Analyst | Assesses property value and LTV |
| 🔎 Critic Agent | Cross-validates all analyses |
| ⚖️ Decision Agent | Generates final risk score and credit memo |

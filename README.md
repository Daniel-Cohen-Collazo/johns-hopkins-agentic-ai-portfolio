# Johns Hopkins Agentic AI Portfolio

A project portfolio built through the Johns Hopkins University Agentic AI Certificate Program (Whiting School of Engineering), focused on applied AI systems, Retrieval-Augmented Generation (RAG), vector databases, multi-agent orchestration, and business-oriented AI use cases.

This repository documents the progression of my work across the certificate, with each project building on the previous one and expanding my hands-on experience with agentic systems.

---

## Portfolio Structure

### Project 1 — DualLens Analytics
A dual-lens analytics project that combines financial performance data with qualitative AI initiative analysis to help evaluate organizations from both a market and innovation perspective.

### Project 2 — Autonomous Financial Analyst
An AI-powered financial research agent that combines stock data, financial news, sentiment analysis, and private-document retrieval into grounded, decision-ready research outputs. Built with LangGraph, OpenAI, ChromaDB, yfinance, and Tavily Search API.

### Project 3 — Senior Mortgage Underwriting System
A multi-agent AI underwriting system that automates residential mortgage loan analysis using six specialized agents coordinated through a LangGraph supervisor workflow. Agents analyze credit, income, assets, and collateral against RAG-retrieved lending policies before generating an audit-ready credit memo and final decision. Tested across three real-world applicant scenarios with 100% accuracy against expected outcomes.

## 📋 Overview

This project expands on earlier work by introducing an **agent-based workflow** that combines multiple research tools into a single financial analysis process.

The system is designed to reduce the time required to gather, compare, and synthesize market data, financial news, sentiment signals, and private-document context — delivering decision-ready research outputs faster than traditional manual methods.

---

## 🚀 What It Does

📊 **Pulls stock price and market data**
Retrieves live and historical stock data using yfinance for quantitative performance analysis.

📰 **Searches financial news**
Uses Tavily Search API to find relevant financial news articles and market commentary in real time.

🧠 **Performs sentiment analysis**
Analyzes tone and sentiment across news sources to surface bullish or bearish signals.

📚 **Queries private files using RAG**
Ingests and retrieves context from private PDF documents using ChromaDB and vector embeddings.

⚡ **Produces grounded financial research outputs**
Combines all data sources into a unified, source-aware research summary that reduces analysis time from hours to minutes.
